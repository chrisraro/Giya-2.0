# Giya

AI-powered loyalty, rewards, and CRM platform for Philippine food & retail SMEs. Consumers scan paper receipts; businesses get campaigns, points, and customer intelligence.

- **Docs (source of truth):** [docs/README.md](docs/README.md)
- **Design system:** [docs/10-architecture/16-design-system.md](docs/10-architecture/16-design-system.md) — living style guide at `/design` when running the app

## Development

```bash
npm install
npm run dev       # http://localhost:3000
npm test          # Vitest
npm run lint
npm run gen:tokens  # regenerate MD3 color tokens from brand seeds
```
